# DS Group — сайт застройщика (dsg.ge)

Сайт для продажи квартир в жилых комплексах DS Group в Батуми. Главная цель — заявки и звонки.

**Стек:** Next.js 16 (App Router) + Payload CMS 3 (админка) + PostgreSQL. Языки: грузинский, русский, английский.

## Что есть

- **Страницы:** главная, проекты (ЖК), страница ЖК, каталог квартир с фильтрами, страница квартиры, акции и рассрочка, новости/блог, о компании, контакты.
- **Заявки:** формы на всех страницах + всплывающее окно «Перезвоните мне». Заявки сохраняются в админке (раздел «Заявки») и отправляются в Telegram.
- **Связь:** плавающие кнопки звонка, WhatsApp и Telegram (на телефоне — нижняя панель).
- **Калькулятор рассрочки:** результат расчёта прикрепляется к заявке.
- **SEO:** серверный рендеринг, мета-теги и Open Graph, `hreflang` для трёх языков, `sitemap.xml`, `robots.txt`, микроразметка Schema.org (организация, квартира, статья, хлебные крошки). UTM-метки сохраняются в заявке.
- **Админка** `/admin` на русском: ЖК (фото, ход строительства, рассрочка, карта, SEO), квартиры (статусы «свободна / бронь / продана»), акции, блог с черновиками, заявки, настройки сайта (телефоны, мессенджеры, тексты главной). Все тексты — на трёх языках.

## Локальный запуск

```bash
cp .env.example .env          # укажите DATABASE_URL и PAYLOAD_SECRET
pnpm install
pnpm seed                     # демо-данные (ЖК, ~110 квартир, акции, статьи); выведет логин администратора
pnpm dev                      # http://localhost:3000, админка — http://localhost:3000/admin
```

> `pnpm seed` удаляет все ЖК, квартиры, акции, статьи и медиа. Заявки и пользователи не трогаются.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `PAYLOAD_SECRET` | Длинная случайная строка |
| `NEXT_PUBLIC_SITE_URL` | `https://dsg.ge` — для canonical, sitemap и Open Graph |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления о новых заявках (бот от @BotFather, чат/группа менеджеров) |
| `SEED_ADMIN_PASSWORD` | Пароль администратора для `pnpm seed` |

## Языки

Настройки — в `src/i18n/config.ts`. Сейчас язык по умолчанию — **русский** (контент пока наполняется на нём). Перед запуском переключить `defaultLocale` на `'ka'`. Если перевод поля не заполнен, показывается вариант на языке по умолчанию.
Тексты интерфейса — `src/i18n/dictionaries/{ka,ru,en}.ts`.

## Структура

```
src/
  app/(frontend)/[locale]/   страницы сайта
  app/(payload)/             админка и API Payload
  collections/, globals/     схемы данных админки
  components/                компоненты интерфейса
  actions/submitLead.ts      приём заявок (с защитой от ботов)
  i18n/                      языки и переводы интерфейса
  lib/                       запросы к данным, SEO, форматирование, Telegram
  seed/                      демо-наполнение
```

## Деплой

Нужен Node.js 20+ и PostgreSQL. Сборка (`pnpm build`) обращается к базе данных. Загруженные файлы хранятся в папке `media/`; на VPS её нужно сохранять между деплоями, на Vercel — подключить S3-хранилище (`@payloadcms/storage-s3`).
