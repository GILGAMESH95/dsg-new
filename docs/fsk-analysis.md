# Анализ fsk.ru и план переноса структуры на DS Group

Дата анализа: 16.10.2026. Источник: главная, страницы проекта (`/amber-city`), новостей, акций, подборщика квартир, ипотеки.

## 1. Карта сайта fsk.ru

| Раздел | URL | Что это |
|---|---|---|
| Главная | `/` | Stories-лента, фильтр + каталог ЖК, «О компании» (bento), способы покупки + калькулятор, стандарт продукта, новости, форма «Перезвоним» |
| Новостройки | `/#list`, `/<slug-жк>` | Каталог ЖК на главной, у каждого ЖК своя страница на корне |
| Квартиры (подборщик) | `/flats` → `/flats/list` | 1204 квартиры, фильтры, «Плитка/Список», сортировка |
| Готовые квартиры | `/built` | Сданные дома |
| Акции | `/promo`, `/promo/<slug>` | «Акции месяца» + «Другие действующие акции», страница на каждую акцию |
| Способы покупки | `/ipoteka`, `/ipoteka/<тип>`, `/rassrochka`, `/trade-in`, `/subsidii`, `/online-booking`, `/insurance`, `/pereustupka` | 8+ страниц ипотеки, рассрочка, трейд-ин и т. д. |
| Коммерция | `/kommercheskaya-nedvizhimost`, `/auction`, `/search-renter` | Отдельная ветка |
| Услуги | `/agent` (вторичка), загородная, ЦФА | Доп. направления |
| О компании | `/about`, `/about/news`, `/about/analytics`, `/about/contacts`, `/about/requisites`, `/about/anti-corruption` | Корпоративный блок |
| Поддержка | `/support#faq`, `/articles`, `/documents` | FAQ, статьи, документы |
| Служебные | `/favorites`, `/consent-*`, `/privat-policy` | Избранное, согласия |

Шапка: логотип, 5 пунктов (Недвижимость, Квартиры, акцентная «Платите как хотите», Акции, Способы покупки, Услуги, О компании), телефон, избранное, личный кабинет. На телефоне — нижняя панель из 5 вкладок: Квартиры, Проекты, Главная, Акции, Меню.

## 2. Главная: порядок блоков

1. Hero — не картинка, а лента «Кратко о главном»: сторис-карточки с видео (ставка, скидки, готовые дома).
2. «Новостройки в Москве и МО» — фильтры в строку (площадь, стоимость, комнатность, срок сдачи, класс) + кнопки «Сбросить» и «На карте».
3. Сетка карточек ЖК, 3 в ряд: фото, название, оранжевые теги (скидка, рассрочка), метро и минуты, «От N млн ₽». В сетке вставлена рекламная плитка «Платите как хотите».
4. «О компании» — bento-плитки с цифрами (>19 млн м², 70 проектов, 15 000 мест в школах, топ-10).
5. «Способы покупки» — вкладки Ипотека / Трейд-ин, лучшие предложения, калькулятор, тумблеры (сертификат, маткапитал, два документа).
6. «Стандарт привилегий» — 10 преимуществ, карусель плиток с иконками.
7. «Новости» — карусель.
8. Форма «Перезвоним в течение 15 минут» + призыв «Подберите квартиру».

## 3. Страница проекта (`/amber-city`)

Порядок секций:

1. Шапка: название, слоган, адрес, «От N млн ₽», кнопка «Выбрать квартиру».
2. «Кратко о главном» — 5 ключевых тезисов + описание, кнопки «Презентация» и «Видео».
3. Сроки сдачи по корпусам.
4. Карта + метро + 4 факта (этажность, метраж, корпуса, отделка).
5. Галерея с вкладками (виды, благоустройство, архитектура, лобби, паркинг, школа).
6. Преимущества (6 пунктов).
7. «Выгодные способы покупки» — акции, привязанные к проекту.
8. Генплан + карточки корпусов: число квартир, срок, цена «от» по каждой комнатности и количество.
9. Расположение и инфраструктура: время до объектов.
10. Подписка на рассылку.
11. Планировки с фильтрами (площадь, цена, комнатность, срок, отделка), плитки по метражу.
12. «Жить в … — это …» — 4 тезиса.
13. Способы покупки и калькулятор (тот же блок, что на главной).
14. «Золотой стандарт продуктов» — 10 пунктов.
15. Новости по проекту, документы, форма «Перезвоним», «Другие проекты».

## 4. Новости, акции, ипотека

- **Новости** (`/about/news`): хлебные крошки «О компании → Новости», фильтр по году, список «заголовок + дата + Читать новость», кнопка «Показать ещё» (подгрузка по 25). Статья: заголовок, дата, «Поделиться», текст, внизу общая форма.
- **Акции** (`/promo`): «Акции месяца» (карточки) и «Другие действующие акции» — заголовок, юридически полный текст условий, срок «до 31.10.26». У каждой своя страница.
- **Ипотека** (`/ipoteka/<тип>`): условия в цифрах (сумма, взнос, срок, ставка), «Кому подойдёт», совместимые программы, калькулятор, схема сделки из 4 шагов, кнопки «Заполнить анкету» и «Консультация».
- **Квартиры** (`/flats`): фильтры (проект, комнаты, цена, площадь, срок, отделка, спецпредложения, особенности планировки), переключатель «Плитка/Список», карточка квартиры: тип, площадь, проект, корпус, этаж, отделка, теги, цена, цена за м², старая цена и скидка.

## 5. Дизайн-система (уже перенесена)

## 6. Сравнение с текущим сайтом DS Group

| Что у ФСК | Что у нас | Разрыв |
|---|---|---|
| Hero-лента сторис | Полноэкранное фото | Заменить на ленту карточек или оставить фото + ленту под ним |
| Фильтры над каталогом ЖК | Нет | Добавить: статус, срок сдачи, район |
| Теги на карточках ЖК | Есть только статус | Добавить поле `tags` в проекты |
| Блок «О компании» bento | Нет на главной (есть `/about`) | Вынести цифры из `settings.stats` в bento |
| Способы покупки + калькулятор на главной | Калькулятор есть (`Calculator.tsx`) | Показать на главной и в проекте |
| Страница проекта: корпуса, генплан, планировки, инфраструктура | Описание, галерея, ход строительства, карта | Нужны корпуса, планировки с фильтром, инфраструктура |
| Акции `/promo` | Нет страницы (`/ru/promotions` отдаёт 404), акции только на главной | Создать страницу и `/promo/<slug>` |
| Ипотека/рассрочка/трейд-ин | Нет | Создать раздел «Способы покупки» |
| Новости с фильтром по году и «Показать ещё» | Блог с категориями | Добавить год и подгрузку |
| FAQ, документы, реквизиты | Нет | Добавить |
| Избранное | Нет | Добавить |
| Подборщик квартир | `/apartments` есть, но в базе 0 квартир | Наполнить данными, добавить список/плитку |

## 7. Предлагаемая структура DS Group

```
/                 Главная
/projects         Новостройки (каталог + фильтры)
/projects/<slug>  Страница проекта
/apartments       Подборщик квартир
/promo            Акции
/promo/<slug>     Акция
/buy              Способы покупки
/buy/mortgage     Ипотека
/buy/installment  Рассрочка
/buy/trade-in     Трейд-ин
/about            О компании
/about/news       Новости
/about/news/<slug>
/about/contacts   Контакты
/support          FAQ
/documents        Документы
```

Нужно учесть три языка (ka / ru / en) и то, что компания работает в Батуми: ипотека РФ, трейд-ин и маткапитал неприменимы, их надо заменить на местные условия (рассрочка от застройщика, банки Грузии, покупка для иностранцев, ВНЖ при покупке недвижимости).

## 8. План работ по приоритету

1. **Страница проекта** — корпуса, планировки с фильтром, инфраструктура, «Жить в … — это …», тезисы «Кратко о главном». Нужны новые поля в `Projects.ts`.
2. **Главная** — bento «О компании», фильтры и теги на карточках ЖК, блок «Способы покупки» с калькулятором.
3. **Акции** — коллекция уже есть (`Promotions.ts`), нужны страницы `/promo` и `/promo/<slug>`.
4. **Новости** — переименовать маршрут в `/about/news`, фильтр по году, «Показать ещё».
5. **Способы покупки** — раздел с 3–4 страницами (нужны ваши реальные условия).
6. **Служебное** — FAQ, документы, избранное.
7. **Данные** — наполнить квартиры, иначе подборщик пуст.

Вопросы к вам перед стартом: какие способы покупки реально предлагает DS Group; есть ли корпуса и планировки по проектам; нужен ли редирект со старых URL (`/blog` → `/about/news`).
